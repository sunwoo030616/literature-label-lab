# 실제 수행 기록

## 기존 활동

사용자의 개별연구 Notion 기록에는 T-MDML, MIML, Hausdorff 거리, LMNN, 라벨 상관관계의 학습·발표 자료가 있다. 계획과 대본이 함께 있어 기존 모델 학습/성능 비교 완료를 추정하지 않았다. 사용자가 제공한 AAAI 논문 원문(그림1, 관계 추정·거리 최적화 수식, 실험 설명)을 확인했다.

## 2026-11-04 후속 구현

1. 원논문과 후속 구현의 경계를 정리했다. 문헌 단일 벡터+라벨 후처리 실험으로 범위를 정하고 T-MDML 전체 재현으로 표시하지 않았다.
2. NCBI 공식 CSV와 Microsoft의 공개 MIT 모델을 다운로드했다. 유료 API/클라우드 학습을 사용하지 않았다.
3. PMID·정규화 텍스트 해시 중복과 누락을 점검하고 실제 분할 manifest·원본 SHA256을 저장했다.
4. 테스트 결과 생성 전에 주 실험 및 특징 이웃 그래프 추가 실험 계획을 작성했다. protocol fingerprint 파일에 당시 테스트 결과 파일 존재 여부를 기록했다.
5. 8,488편을 max_length=256, frozen encoder, attention-mask mean pooling으로 실제 MPS 인코딩했다. 모델 추출은 약 391초였다. 이 시간은 분류기 학습이나 API 응답시간과 다르다.
6. 모델·정책 학습, 고정 설정 테스트, 오류 분석, warm-up 배치 실험을 코드로 실행했다. raw 결과와 실행 로그를 보존한다.
7. 로컬 API 및 입력/바쁨/실제 추론 smoke 검사, 결과 무결성 검사, 제출용 PDF 렌더 검수를 수행한다. 완료 여부는 각 결과 파일 및 최종 검증 기록을 확인한다.

## 기록 원칙

결과가 좋지 않아도 기존 결과를 지우거나 test를 보고 최적화하지 않는다. 이후 수정은 별도 버전의 개발 실험으로 표시한다. 이번 코드를 이전 학기부터 개발한 것처럼 기간을 늘려 쓰지 않는다. 제출 시 본인이 실제로 이해·검증한 내용을 설명한다.

## 완료 확인

- 주 실험 24조건 + 특징 그래프/무작위 이웃 6조건 완료.
- 데이터 분할 ID/해시 무결성, 정책 저장 순서, 30조건 결과 범위 검사 통과.
- 수학/평가 경계 5개 자동 검사 통과. 실제 모델 API smoke 6개(health·잘못된 입력·바쁨·실제 추론 3건) 통과.
- 포폴 추가용 PDF 3페이지를 PNG로 렌더링하고 전체 페이지 확인. 그래프 라벨 겹침을 수정했다.
- TF-IDF 평균 Macro-F1 .7789, frozen BiomedBERT .7462, 공존 관계 .7499, 특징 그래프 .7472. 복잡한 방식의 일관된 우위를 확인하지 못했다.
- 검토 보류 정책은 calibration 목표를 만족했지만 테스트에서 .85 sample-F1에 미달했다. 보고서/PDF에 명시했다.
- 테스트 결과 이후 분류/선택 로직은 바꾸지 않았다. 후속 수정은 metadata의 cache_used 표시 수정, 재현용 오류 분석 스크립트 추가, 보고서·그림 배치 수정이다.
