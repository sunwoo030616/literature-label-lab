# 공고와 이번 프로젝트를 연결하는 방법

사용자가 제공한 2027년 동계 연구연수생 모집분야 원문 1쪽의 실습 내용을 기준으로 정리했습니다. 아래는 프로젝트의 관련성을 설명하는 것이며, 해당 연구실의 실제 시스템을 구현했다는 뜻은 아닙니다.

| 지원코드 | 공고의 구체적인 실습 내용 | 이번 결과에서 보여줄 증거 | 설명의 경계 |
|---|---|---|---|
| K2027-02 언어지능연구실 | 평가 데이터 수집·정제·형식 통일, Python 평가 스크립트, 소형 모델 학습·추론 속도/메모리 측정, 동일 조건 비교·검증 | 데이터 ID/해시·중복 감사, tune/calibration 분리, 기존 실패 보존, 고정 문헌의 LoRA 병합 전후 확률·처리량 비교, 검증 코드 | HERMES-Net 구현·검증 경험은 아님. partial vs LoRA는 epoch/dropout이 달라 순수 구조 비교로 쓰지 않음 |
| K2027-05 시각지능연구실 | 과학 문헌 메타 리뷰를 위한 데이터 확보 및 모델 개발 지원 | 공개 생의학 문헌 다중 주제 분류, 문헌 bag·라벨 관계 대조, Qwen 원문 인용 추출, 사람 검토 이력 분리 | 완성된 체계적 문헌고찰이나 연구결과의 임상적 근거평가는 아님 |
| K2027-03 시각지능연구실 | 과학문헌 탐색과 지식베이스 구축을 위한 에이전트 개발·데이터 정제 | V1 관련 문헌 검색, 주제별 구조화, 모델 버전·검토 상태·근거 이력 API | 현재는 단계가 명확한 workflow. 자율적으로 계획·도구 선택하는 완성형 에이전트를 구현했다고 쓰지 않음 |
| K2027-07 데이터지능연구실 | 화학·바이오 QA 벤치마크 구축, 지식 구조화, 지식 그래프 기반 RAG 지원 | 바이오 문헌 정제·분할 무결성, 복수 주제 annotation, 인용 문자열 검증 | 이번 실험은 QA benchmark나 KG-RAG가 아님. 라벨 공존 행렬을 과학 지식 그래프라고 부르지 않음 |

## 포트폴리오의 권장 중심

02/05의 실습 내용과 연결하기가 가장 구체적입니다. 제목은 **“생의학 문헌 다중 주제 분류: 저성능 원인 진단부터 무료 미세조정·근거 검토까지”**로 두고, 논문 개념 → 최초 실패 → 원인 분리 → 후속 비교 → 검토 서비스 순으로 설명합니다. 지원코드가 확정되면 해당 코드의 연결 문장을 한 줄 추가하고 모든 분야에 맞는 프로젝트처럼 나열하지 않습니다.

- 02 강조 문장: “모델 이름보다 비교 조건과 검증 코드를 먼저 고정하고, 품질과 실제 로컬 실행 비용을 함께 측정했습니다.”
- 05 강조 문장: “문헌의 복수 주제를 분류하고 원문 인용 후보를 추출하되, AI 예측과 사람 검토를 분리해 추적할 수 있도록 구현했습니다.”

최종 수치는 REPORT.md의 동일 분할·동일 조건 행에서 가져옵니다. 유리한 단일 seed만 대표 결과로 제시하지 않습니다. 기존 개별연구는 이론 학습이고 이번 코드·학습은 2026년11월 후속 개발이라는 시간 구분을 유지합니다.
