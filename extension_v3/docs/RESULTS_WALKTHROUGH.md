# 먼저 읽는 결과 해설

**이 프로젝트는 “처음 낮게 나온 생의학 문헌 분류의 원인을 조사하고, 실제 무료 미세조정과 후속 가설을 검증한 연구 프로토타입”입니다.**

입력은 공개 LitCovid 문헌의 제목·초록이고, 출력은 치료·진단·예방 등7개 주제의 복수 라벨입니다. 하나의 문헌에 여러 주제가 동시에 붙을 수 있습니다. 논문 PDF 본문 전체를 처리하는 시스템은 아닙니다.

## 1. 가장 먼저 기억할 결과

아래는 **모든 모델과 임계값을 고정한 뒤 처음 확인한 새 내부1,000편**의 Macro-F1입니다. 각 주제 F1을 같은 비중으로 평균한 값이며, 문헌 정답률과는 다릅니다.

| 조건 | Macro-F1 |
|---|---:|
| 최초 frozen BiomedBERT, seed17 | .7474 |
| 같은 표현에서 분류기 규제만 조정 | .7889 |
| 튜닝한 단순 TF-IDF, seed17 | .7930 |
| 마지막2개 층 부분 미세조정, seed17 | .8068 |
| LoRA256, seed17 | .7937 |
| LoRA256, seed42 | .8056 |
| LoRA512, seed17 | .7951 |

C값은 frozen 벡터 위 Logistic Regression의 설정이고, 미세조정 head는 별도 BCE 학습 조건입니다. 부분 미세조정은3epoch, LoRA는1epoch이고 dropout·batch·padding도 달라 구조 하나의 우열을 증명한 비교는 아닙니다. 새 표본도 같은 LitCovid 출처이므로 외부 도메인 검증은 아닙니다. 결과를 본 뒤 기본 API 모델이나 임계값을 바꾸지 않았습니다.

## 2. 왜 처음 BiomedBERT가 낮았나요?

확인한 원인 중 하나는 **분류기 과적합**입니다. 같은 문헌 벡터에서 C1은 학습 .981/검증 .776, 규제가 강한 C.01은 학습 .869/검증 .813이었습니다. 연습문제 점수가 내려가도 새 문헌을 더 잘 맞힐 수 있었습니다.

새 내부 표본에서도 규제 조정의 개선은+.0414였고, 고정 모델의 문헌 재표집95% 구간은[+.0157,+.0640]이었습니다. 원래 모델 이름만으로 성능을 판단하기보다 학습·검증 간격과 분류기 설정을 점검한 근거입니다.

**미세조정이 단순 모델을 확실히 이겼다는 결론은 아닙니다.** 부분 미세조정과 튜닝 TF-IDF의 차이+.0138은 같은 방식의 구간[-.0196,+.0452]이0을 포함했습니다. 구간은 문헌 재표집만 고려하고 모델 선택·새 도메인의 불확실성은 포함하지 않습니다.

## 3. 더 개발했는데 안 좋아진 것도 있나요?

있습니다. 그대로 보존했습니다.

- **긴 입력:** 기존 테스트에서 LoRA256 .8132→LoRA512 .8034로 낮아졌습니다. 유행 예측 주제를 잡아낸 문헌은32→37편 늘었지만 오탐도26→48편 늘었습니다. 새 내부 표본에서는 차이가+.0015로 작고 불확실성 구간도0을 포함했습니다. 길게 읽는 것이 항상 유리하다고 말할 수 없었습니다.
- **임계값 안정화:** 검증600편 내부 교차분할로 공통/라벨별 경계를 섞는 대조를 추가했습니다.512의 새 내부 점수는 .7951→.7968이었지만 차이의 구간이0을 포함했습니다. 원래 정책을 지우거나 최종 표본으로 재튜닝하지 않았습니다.
- **문헌 bag attention:** 새 내부 표본의3개 학습 부분표본 평균은 균등 비중 head .7747, 학습 attention .7408이었습니다. seed17의 학습/검증 점수 간격도 attention .084, 균등 head .027로 더 컸습니다. 이번 작은 head 구성에서 더 유연한 가중치가 일반화에 도움이 되지 않았다는 관측입니다. 모든 attention 방식이 나쁘다는 뜻은 아닙니다.
- **라벨 관계:** 실제 관계 .7415, 무작위 관계 .7424로 실제 관계의 고유한 이득을 확인하지 못했습니다. 선택 lambda0과 약한 penalty의 크기도 기록했습니다.
- **확률 보정:** calibration에서는 NLL이 낮아졌지만 기존 테스트·감사에서 NLL/Brier는 나빠졌습니다. 분류 결정은 유지됐습니다. 신뢰도 향상을 성공 결과로 쓰지 않았고 API에는 원래 점수와 실험적 변환값을 구분해 남겼습니다.

attention이 높은 조각을 제거하면 예측이 더 크게 바뀌었지만, 이것은 입력 민감도입니다. 그 조각이 정답의 근거라는 인과적 증명은 아닙니다. 조각은 의미 단위 문단이 아니라 고정 길이 token window입니다.

## 4. LLM은 실제로 무엇을 했나요?

무료 로컬 **Qwen3-4B-4bit**에게 주제와 원문 인용을 JSON으로 생성하게 했습니다. 고정40편에서 zero-shot과 train-only 예시3개를 넣은 few-shot을 비교했습니다.

| 같은40편의 방식 | Macro-F1 |
|---|---:|
| Qwen zero-shot, 원시 주제 | .2927 |
| Qwen few-shot, 원시 주제 | .3648 |
| 미세조정 LoRA256 분류기 | .6331 |

Qwen의 가중치를 학습한 것은 아니며, **실제로 미세조정한 모델은 BiomedBERT의 일부/LoRA**입니다. 이40편에는2개 주제의 정답이 없었고 학습·입력 예산도 서로 달라, 모델 계열 전체의 우열이나 최종 테스트 성능으로 일반화하지 않습니다.

원문에 문장이 그대로 있는 비율은86.0%→89.7%, 라벨·15~240자·원문/모델 입력 일치를 모두 통과한 비율은79.1%→79.4%였습니다. 규칙 필터는 오탐뿐 아니라 맞는 라벨도 제거했습니다. 원문에 있는 문장이라는 사실과 해당 주제를 논리적으로 뒷받침한다는 사실은 구분했습니다.

## 5. 백엔드까지 연결한 부분

실제 LoRA 분류기와 Qwen을 API에 연결했습니다. 내용 해시+모델 버전으로 문헌을 구분하고, AI 예측·LLM 후보·사람 검토 결과를 따로 저장합니다. 오래된 revision의 검토는409로 거절하고 재시작 후에도 상태가 유지되는지 검사했습니다. 모델이 읽은 길이와 잘림 여부도 표시합니다. 검토 smoke에는 실험용 정답을 넣었으며 실제 사용자 실험은 아닙니다.

LoRA 추론 병합도 실제32편/batch8/3반복에서 비교했습니다. 최대 확률 차이는8.35e-7, 라벨집합은32편 모두 같았습니다. 중앙 처리량은23.9→26.6문헌/초였지만 고정 순서·작은 표본·동일 desktop의 관측으로 일반적인 배속은 아닙니다. 원본 checkpoint는 그대로 남겼습니다.

## 6. 면접에서30초로 설명하면

> 개별연구에서 배운 bag·라벨 관계 개념을 생의학 문헌 분류로 확장했습니다. 처음 낮게 나온 frozen BiomedBERT의 분류기 과적합을 찾아 규제를 조정했고, 무료 모델을 실제 부분·LoRA 미세조정했습니다. 긴 입력·attention·관계 규제·LLM 예시 학습을 비교하면서 개선되지 않은 조건도 보존했습니다. 마지막에는 모델을 고정한 새 내부 표본으로 확인하고, 근거 후보와 사람 검토를 분리하는 API까지 연결했습니다.

기존 이론 학습과 이번2026년11월 구현을 구분합니다. T-MDML 전체 재현·SOTA·Qwen 미세조정으로 주장하지 않습니다. 구현에 사용한 AI 코딩 지원과 본인이 직접 이해·확인한 범위도 구분해서 설명합니다.
